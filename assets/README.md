# 图片资源

`index.html` 通过相对路径加载本目录，保留目录结构即可离线使用；分发或部署时须同时包含 HTML 与 assets。页面没有内嵌图片 base64，也不请求远程图片。

原有图片从 HTML 提取，保持原图内容。新增立绘使用内置 image_gen 生成（非 CLI），WebP 仅做格式转换，未改变构图。原始生成文件保留在 Codex 的 generated_images 目录；页面使用本目录的 WebP。
