# 月光古堡人物配音

使用本机 IndexTTS2，在 Apple MPS 上串行生成。每次仅运行一个模型进程，模型运行时不并发转码或启动浏览器回归；转码和验证在生成进程完全退出后依次运行。采用保守 MPS 内存水位、半精度、短句拆分、关闭编译与加速。已完成源 WAV 保留，重建清单只列尚未生成的片段。

`plan.json` 是原对白 → 明确说话人 → 原始短片段的映射；`acting-directions.cjs` 为逐句人工核对的表演指导，记录当前处境、情绪走向、轻重与停顿。同一段多次开口可有不同情绪，不把同角色的所有台词合成一种腔调。IndexTTS2 接收每个片段独立的八维情绪向量；向量顺序来自本机 `infer_v2.py`，并非臆测。每段同时保留前文、当前语境和后文。

角色固定参考音色，使用本地 CSEMOTIONS 的 Apache-2.0 参考库；来源为 `https://huggingface.co/datasets/ATH-MaaS/CSEMOTIONS`，具体参考和其来源记录在 `plan.json` 的 `cast` 中。角色名只是游戏配音分工，不代表模仿对应真人。音调小幅调整用于区分角色，语速依每句情绪设置；不在游戏中实时变声或调用云端接口。

表演处理示例：十元发现床下物件时压低并发抖；艾德里安阻止离开时压住怒意，重逢时难以置信与哽咽，日出后转为温暖和打趣。宝石与飞鸿有独立声音与明确台词归属。只读角色真正说出口的话，动作描写、系统操作提示、文献字句与“像一句我知道”等比喻保持字幕，不冒充角色发言。原剧本明确无声的唇语同样不生成角色声音。

当前正式声音为 `source/emotional-v2/` 下的源 WAV。早期固定语气的 v1 试音仅保留作对照，记录在 `flat-v1-plan.json`；不进入正式配音索引。`package-moonlight-castle-voices.py` 将同一句的短片段串行拼接为一个 MP3，先正确重采样到 24kHz，再做保速调音、响度规范及短停顿；游戏不下载原始 WAV。

入口接线在 `js/audio/moonlight-castle-voice.js`：新对白自动切换、当前句重听、独立人物配音开关与音量、与总静音和后台／暂停联动，人物说话期间 BGM 压到原音量的 20%。存档继续不自动重播旧句；游戏故障或不支持音频时保留原字幕并提供重试，不阻塞解谜。原 28ms 打字效果保留。自动衔接的伯爵对白与女巫出题等待前一句配音结束，玩家主动点击仍立即切换。

延迟出现的物品补充提示只在玩家仍读同一段时显示，避免覆盖已经开始的交谈。排队的新遭遇等待当前人物录音、其待续问题及答题弹窗结束后再触发，不抢掉出题；已经开始的追逐和信物倒计时不因此暂停。

重建顺序：

1. `node scripts/build-moonlight-castle-voices.cjs` 生成仅含缺失片段的 `pending.jsonl`。
2. 在本机 IndexTTS2 环境运行 `scripts/render-moonlight-castle-voices.py`，工作目录为 IndexTTS2 仓库，使用其 `.venv/bin/python`。该脚本固定 MPS／FP16、默认单束解码、两条 CPU 线程、不启用编译或额外加速；明确标记的重录使用清单中的三束参数。每个片段结束后清理解码缓存，同步逐句推理；文件锁禁止第二个配音进程，原子写入避免把中断片段当成完成。支持 `--limit N` 试音。**不得同时启动第二个生成进程，也不要同时运行转码、语音识别或浏览器回归。**
3. 待该进程完全退出，运行 `python3 scripts/package-moonlight-castle-voices.py`；正式模式要求源片段齐全。
4. 运行 `python3 scripts/check-moonlight-castle-voices.py` 串行解码检查；在安装 `mlx_whisper` 的本机 Python 环境加 `--transcribe` 可逐条转写对照。自动相似度只标记需要复核的内容，同音字与人名识别误差不自动当成配音错误。所有处理共用同一文件锁，拒绝与生成并行。
5. 运行 `node scripts/version-assets.cjs` 与 `--check`，再依次运行相关浏览器回归。

`audio-report.json` 记录正式 MP3 的时长、体积、人物和完整性。未完成全部生成与核验时，不将试音或部分索引称为正式完成版。

本次完整转写、重录原因与核对记录见 [qa-review.md](qa-review.md)。合成时对英文专名和个别词的辅助读法单独记录，保留原字幕；重录不改变已通过的声音。正式 MP3 文件名包含源音频内容指纹，重录后会使用新地址，避免浏览器复用旧声音。
