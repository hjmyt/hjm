# 月光古堡正式版

入口：主游戏首页右下角悬浮南瓜 → 惊悚／密室逃脱确认弹窗 → 根目录 `moonlight-castle.html`。支持 HTTP 静态部署和直接打开 HTML；返回链接固定到 `index.html#home`。不需要打包或外部 CDN。

保留用户粗版的七个房间、三周目、六位寻名、钢琴／书架／五声／大键琴／密码谜题、四封信、信物禁锢、三种追逐、三个收集条件结局，以及日出后的十一件纪念品。完整原稿保留在 `source/prototype.html`，其中内容仅作为剧情与玩法来源。正式版不增加音符、羁绊或入场消费，不修改主游戏存档结构。

封面将完整原稿前情作为默认展示的独立阅读区域；进入按钮位于全文之后。正文不折叠、不做限高截取，横竖屏均随封面自然滚动，封面引语保留完整原句与出处。

场景调查与人物对白保留原稿每字 28 毫秒的打字效果及光标。暂停与后台同步停字，新对白取消上一段动画；手记和现有 v1 存档始终保存完整文本，刷新继续时完整显示已保存的该段对白。

钢琴白键与黑键按下时下压并亮起金色，轻点后保留约 220ms 反馈；触摸按住持续显示，松开、取消和切后台清理。静音时仍有视觉反馈，不显示琴键音名、不改变谜题顺序或重复计入按键。

对白区域按屏幕尺寸预留固定高度及交谈按钮空间，长文在框内滚动；逐字换行、打字结束和交谈按钮显隐不再改变场景图及其热点坐标，避免边阅读边缩放。

手机版（视口宽度不超过 1000px）进入探索后收起顶部「月光古堡」标题栏，主场景从屏幕顶部开始，房间名改成叠在画面上的小标签。周目、时长、声音、暂停、全屏及返回乐团的同一组控件移入「设置」抽屉；封面保留原标题栏，切回桌面宽度时控件回到顶部。无重复控件、额外监听或新存档字段，信物倒计时与故障提示继续可见。

手机横竖屏的主图始终保留原始宽高比，默认等比铺满场景，半透明对白叠在画面上。支持上下左右拖动、双指以触点为中心缩放，以及加减按钮缩放；原图全景与默认大画面可一键切换。全景暂收字幕并避开顶部工具，点击人物／物品会自动返回带字幕的大画面；边缘线索不会永久丢失。纵向拖动额外留出字幕与底部工具栏的余量，使下方线索可移至字幕上方。人物、物品和房门共用实际显示尺寸与二维平移量；拖动及缩放不会误触调查／对话，普通重绘不重置视野。字幕仍逐字显示，长文在字幕区域内滚动，文字长度不改变图像几何。不使用纵向拉伸，不修改存档。

## 统一探索与独立高清图（2026-10-16）

每个房间固定一张人物与物品同场的高清图，取消调查／人物画面切换。点击人物交谈、点击物品调查、点击门移动；底部「探索」抽屉同时列出人物与物品，方便小屏选择。场景画面随对白框高度留出操作空间，避免遮住下方的物品与人物。v1 旧存档中的 objects／people 模式字段继续兼容，读取后统一进入同场探索。

七个房间、日出与封面共九张图使用内置 Image2 **逐张独立生成**，正式版不使用八合一裁图。人物长相以对应正式角色卡为准，服装按古堡原稿覆盖：叶思阳执事制服／领结／铜扣、Tim 骑士铠甲、十元黑白女仆装、垃垃紫色女巫袍、柒柒占卜戏服；Jerry 持小号，笛杰持竹笛。餐厅三位实际在场角色采用明确群像例外。无正式角色卡的艾德里安继续使用空塔楼与对话入口。

原图保存在 `assets/moonlight-castle/source/individual-v3/`，逐房间参考、实际提示词、语义映射和核对联系表在 `docs/imagegen/moonlight-castle/individual-v3/`；`node scripts/build-moonlight-castle-individual.cjs` 只做独立原图的等比 WebP 编码，不放大低分辨率裁图。

另有八张独立高清过场图，覆盖死亡／真相转场、追逐、Wrong Ending、三个乐章结局与乐谱补全，合计十七张现行独立 CG。全屏过场采用配图背景加渐暗遮罩，文字与操作按钮叠在图上；长文独立滚动，背景固定，横竖屏均保留全文。来源、逐张提示词与语义映射见 `docs/imagegen/moonlight-castle/outcomes-v1/`；无正式角色卡的古堡人物以环境与魂光表现。

## 代码入口

- `js/data/moonlight-castle.js`：原稿剧情、物品、谜题、房间出口、固定人物集与语义画面 ID。
- `js/features/moonlight-castle-game.js`：解谜、循环、道具、对话和收集规则。
- `js/features/moonlight-castle-ui.js`：人物与物品同场探索、场景热点、触摸／键盘、背包、手记、提示、暂停、导入导出。
- `js/core/moonlight-castle-state.js`：v1 显式独立存档、可读备份、故障原文保护及单调可暂停游戏时钟。
- `js/audio/moonlight-castle.js`：五首用户 BGM、配乐开关／音量、播放失败重试、后台停止、钢琴与竹笛反馈音。
- `js/audio/moonlight-castle-effects.js`：本地合成低音琴弦、金属锁扣、木门铰链、暗格、玻璃与音乐盒；不请求外部素材。
- `js/data/moonlight-castle-voices.js` 与 `js/audio/moonlight-castle-voice.js`：原句到人物录音的显式索引、串行播放、重听、配音音量、配乐自动压低、暂停和后台联动。
- `js/app/moonlight-castle-bootstrap.js`：唯一独立页面启动入口。
- `js/features/moonlight-castle-entry.js`：由主游戏最后的 bootstrap 绑定一次南瓜事件。
- `styles/moonlight-castle-immersive.css`：月光氛围与粒子、过场、发光标记、人物姓名牌、背包／手记／地图／设置抽屉、横屏工具栏和全屏降级。
- `styles/moonlight-castle-outcomes.css`：全屏过场与结局 CG、叠字渐暗遮罩、长文滚动、追逐与暂停背景、物件剧情插图。
- `styles/moonlight-castle*.css`：独立深色主题、谜题与首页入口；单屏沉浸画面、人物站位按钮和抽屉式工具。手机优先横屏，支持 844×390／568×320 等横屏，也保留竖屏操作；全屏与旋转锁定不受支持时可直接继续游玩。

所有本地脚本按依赖 `defer` 加载，两个 HTML 都由 `node scripts/version-assets.cjs` 维护资源内容哈希。独立页复用主游戏人物目录和 `cardImage(card, 'avatar')`，不复制角色定义。

## 场景移动

地图中的已连通房间可以直接点击进入；跨房间移动沿实际出口逐步执行，仍检查钥匙、蜡烛、追逐和循环转场，不跳过锁门。当前房间与尚未连通的房间明确标注状态。场景中的房门／楼梯入口在调查与人物模式都显示名称、开启条件与可点击的进入状态；钢琴解锁书房时立即同步，刷新后保留。房门位置显式配置在 `CASTLE_SCENE_DOORS`，钥匙规则统一在 `CASTLE_DOOR_RULES`，地图与预载复用执行层 `castleDoorAccess()`。

## 进度与时钟

古堡进度保存在 `hjm-moonlight-castle-v1`。v1 JSON 包括 `game`、`phase`、`elapsed`、手记、提示次数、场景视角和必要转场状态。缺失后来新增的可选字段从默认值补齐；不接受不识别的版本、损坏 JSON 或非法核心结构。主游戏读档、货币和羁绊均不接触此键。

正常保存将上一份通过校验的 JSON 存到 `.backup`。异常当前值先独立保留到 `.damaged`，优先恢复可读备份；无法恢复时停止自动保存，保留原始值并显示导出原文／明确重新开始入口。恢复外部 JSON 必须先校验，再由玩家确认替换；导出当前进度与导出故障原文为不同操作。

刷新后在封面选择继续，恢复房间、物品、谜题、名字、周目、日记、信物剩余时间及结局。尚未完成的过场会重新排入时钟，避免刷新卡住循环。追逐中刷新恢复剩余危险时间并重新进行该次动作。页面进入后台或主动暂停时，游戏时钟停止，BGM 与音效停止；回到前台显示手动继续，避免阅读切回时突然失败。

结局阅读页一直显示，直到玩家选择进入日出或返回乐团；不自动关闭。三个结局的乐章由原稿收集条件判定，日出 BGM 从结局展示开始切入。

## 配乐

五份用户 MP3 按原文件完整复制，无截断或变速。文件名、时长、编码与来源记录在 `audio.json`：第一／二／三周目、Wrong Ending、HE 日出分别使用对应文件。播放失败时按钮显示“点此重试”，手机自动播放限制时允许下一次点击启动。

钢琴正确旋律触发一次「低沉共鸣 → 远处金属锁扣」；钥匙开锁、实际进入房间、摇动锁门、打开书架／地球仪暗格、琴盒／珠宝盒、敲碎镜片、音乐盒与大键琴校准各绑定自己的声音。音效由实际动作显式触发，不匹配对白文字，重绘和继续存档不补放。声音开关及音量同时控制 BGM、音效和乐器提示音；暂停、后台与离开页面立即终止当前及已排定的音效，恢复后只播放新的动作。音效输出增益为 1.15，较初版 0.7 提升约 4.3dB；音效／乐器音发声时，BGM 用约 55ms 降到设定音量的 42%，最后一个声音结束后约 260ms 平滑恢复。音效总线带动态限幅以控制多个声音叠加时的峰值。

## 美术与回归

人物配音采用本地 IndexTTS2，逐句按所处周目、动作和情绪生成，宝石与飞鸿分别配音。同一句中的惊讶、哽咽、释然等情绪转折单独处理；旁白、动作、文献和明确无声的唇语保留字幕。新对白自动播放，点「重听」可重播；设置中可独立开关、调整人物配音，仍遵循整体静音。说话时 BGM 自动降至原音量的 20%，结束后平滑恢复。自动出题及后续对白等待实际说完，切换场景取消旧句的自动衔接；读档继续只显示旧对白，不自动重播。音色来源、逐句表演指导和串行重建方法见 [人物配音说明](voices/README.md)。

独立高清原图、角色参考、提示词、语义映射与 QA 联系表见 `../imagegen/moonlight-castle/`。正式图重建运行：

```sh
node scripts/build-moonlight-castle-individual.cjs
node scripts/build-moonlight-castle-outcomes.cjs
node scripts/version-assets.cjs
node scripts/version-assets.cjs --check
node tests/moonlight-castle.cjs
node tests/moonlight-castle-immersive.cjs
node tests/moonlight-castle-typewriter.cjs
node tests/moonlight-castle-unified.cjs
node tests/moonlight-castle-sound.cjs
node tests/moonlight-castle-voices.cjs
node tests/moonlight-castle-outcomes.cjs
```

需要 Node.js 的 sharp、Playwright；Playwright 使用本机浏览器时设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。浏览器回归使用隔离上下文，覆盖首页确认、三周目真实按钮解谜、三个结局、配乐切换、暂停、故障保护／备份恢复／明确重置／导入、旧 v1 进度、下一图预载、320／390／720／768／1440 屏宽及手机横屏与 file/HTTP。Chromium 手机模拟不替代 iPhone 真机验收。
