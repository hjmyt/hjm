# 第七章插图上下文一致性审查（2026-10）

本轮修复了把“对白中提到的人”误当成“当前在场人物”的生成规则，并把相邻旁白复用改为逐点击页独立语义图。审查覆盖 446 个运行时阅读页；生成计划含 448 个源格、56 张八合一母图，其中 2 个旧源格保留供历史重建但不再由运行时引用。

## 判定顺序

1. 当前页有明确说话人时，以说话人为主。
2. 同一场景连续对白只有一人发言时，可保留前后页已经确认的对话对象。
3. 旁白只识别现实动作中的人物，忽略引号内被转述、回忆或讨论的人名。
4. 每格最多两名有名角色；只有“屋里坐着七个人”的开场介绍使用一次显式七人群像例外。前后页上下文只延续地点、视线、道具、情绪和服装。
5. 未列入 `Visible named cast in the current physical location` 的名字即使出现在台词中也不得入镜。

## 重点复核

- `q_washroom_p5`～`q_washroom_p7`：洗手间内只有冰冰和柒柒；周总只是冰冰谈及的求婚对象，不在现场。
- `q_expose_p10`～`q_expose_p11`：叶思阳连续质问朱老师，镜头保持叶思阳与朱老师，不延续上一页的小塔。

- 空格与小塔：空格双腕无饰品；多圈深色手串仅属于小塔。
- `q_event2_p3_fix`：柒柒持壶倒茶并停顿，TIM 只拿名单，不得交换动作或道具。

## 图文顺序复核

- 逐一检查了 56 张基础八合一母图、15 张柒柒服装修正母图及其裁切映射，并核对所有 34 个剧情节点的 446 个阅读分页顺序。
- 发现序章 `q_start_p2` 与 `q_start_p3` 的生成语义相邻错位：招牌图已经生成，但原数组映射把它提前用于“参与演出”的旁白页；真正出现“山丘酉馆”的第 6 个阅读页反而显示人物图。
- 修复后使用稳定语义 ID 显式绑定：`q_start_p2` 固定为“山丘酉馆”招牌环境图；拆开的逐句旁白分别使用 `*_readN` 语义 ID，不再因为原先相邻合并而共享错误画面。
- 运行时 446 个点击页的画面 ID 全部唯一。回归遍历全部阅读分页，校验每页 ID 能在生成计划中解析，并检查当前台词与绑定画面文案一致；浏览器回归另锁定“山丘酉馆”、柒柒倒茶和朱老师缺席三个纠错页。
