# 第七章个人线场景插图

四条路线共 188 个阅读节点：阿喆 36、十元 69、宝石×飞鸿 26、羊村 57。全部长节点均按实际阅读分页配置场景图，当前路线共使用 323 张独立剧情插图；重建清单另保留 1 张未用于当前阅读页的历史素材。羊村严格按用户提供的原稿拆成 141 个阅读页，每屏一图，不复用角色立绘代替情节。

- `plan.json`：43 张 4 列 × 2 行八合一的正式场景清单；第 15～18 张为宝石×飞鸿节点封面，第 19～22 张为其逐页补图，第 24～26 张补齐阿喆与十元分页，第 27～44 张为羊村线 141 屏。
- `01-personal.txt` 至 `22-personal.txt`、`24-personal.txt` 至 `26-personal.txt`、`27-yangcun.txt` 至 `44-yangcun.txt`：内置图像生成工具的提示词。角色参考来自项目现有卡册立绘。
- `23-personal-fix.txt`、`27-personal-fix.txt`、`page-fixes.json`：逐格复查后的角色造型与第一人称视角校正；修订原图为 `23-personal-fix.png` 和 `27-personal-fix.png`。
- `02-personal-fix.txt`、`04-personal-fix.txt`、`12-personal-fix.txt`：冰冰性别与气质、玩家视角及单场景构图的修订提示词。
- `art.json`：每张裁图的原图、原图尺寸、格号、裁切坐标、绑定 ID 和最终文件。坐标为 `[left, top, right, bottom]`，内缩 3 像素以去掉拼图分隔线。
- `assets/chronicle/personal/source/`：生成原图与修订前版本。羊村正式母图为 `27-yangcun.png` 至 `44-yangcun.png`；`36-yangcun-panel7.png` 留存“抓住前臂”动作的单格修订原图，且已回填到第 36 张八合一母图。其他未使用格为留存的场景细节图，不参与剧情收藏。
- `assets/chronicle/personal/<节点>.webp`：浏览器加载的最终图片。

重建：`python3 scripts/crop-personal-art.py`。只生成已存在批次时可传 `--partial`。不要只替换回忆详情图：剧情、相册、详情和下载共享同一图片映射。

已逐格检查八合一边界、剧情主体与分支情绪，并校正误带眼镜／乐器、十元外形漂移、玩家被画成男性及大羊身份不清等问题。冰冰为长发、亮眼优雅的女性大提琴手；雪子为长黑发束在脑后、黑色层叠穿搭的男性键盘手。十元保持短卷棕发、星形发夹与米白针织装束。宝石保持黑色微卷短发与米白衬衫，飞鸿保持黑色短发与蓝灰衬衫，二人不得互换造型。柒柒以卡册旗袍与盘发为准，非演奏场景不强行持琴；REK 以卡册正式立绘为准，是中长发、黑框眼镜、短胡茬、黑色宽松穿搭的成年男性。玩家使用第一人称视角，避免在不同个人线之间误配恋爱对象。
