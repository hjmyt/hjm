# 第七章个人线场景插图

三条路线共 132 个阅读节点：阿喆 36、十元 69、宝石×飞鸿 27，共使用 163 张剧情插图。宝石×飞鸿的长节点按阅读分页拆分，共 57 个对白分页，每页都有对应场景图；不复用角色立绘代替情节。

- `plan.json`：22 张 4 列 × 2 行八合一的逐格场景清单；第 15～18 张为宝石×飞鸿节点封面，第 19～22 张为逐页补图。
- `01-personal.txt` 至 `22-personal.txt`：内置图像生成工具的提示词。角色参考来自项目现有立绘。
- `23-personal-fix.txt`、`page-fixes.json`：逐格复查后对飞鸿求助、宝石翻旧相册两格进行人物造型校正；修订原图为 `23-personal-fix.png`。
- `02-personal-fix.txt`、`04-personal-fix.txt`、`12-personal-fix.txt`：冰冰性别与气质、玩家视角及单场景构图的修订提示词。
- `art.json`：每张裁图的原图、原图尺寸、格号、裁切坐标、绑定 ID 和最终文件。坐标为 `[left, top, right, bottom]`，内缩 3 像素以去掉拼图分隔线。
- `assets/chronicle/personal/source/`：生成原图与修订前版本。第 14 张只使用第 1 格；第 18 张使用前 3 格，第 22 张使用前 7 格；未使用格为留存的空琴房细节图，不参与剧情收藏。
- `assets/chronicle/personal/<节点>.webp`：浏览器加载的最终图片。

重建：`python3 scripts/crop-personal-art.py`。只生成已存在批次时可传 `--partial`。不要只替换回忆详情图：剧情、相册、详情和下载共享同一图片映射。

已逐格检查八合一边界、剧情主体与分支情绪，并校正误带眼镜／乐器的两格。冰冰为长发、亮眼优雅的女性大提琴手；雪子为短发男性。宝石保持黑色微卷短发与米白衬衫，飞鸿保持黑色短发与蓝灰衬衫，二人不得互换造型。玩家使用第一人称视角，避免在不同个人线之间误配恋爱对象。
