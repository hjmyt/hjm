# 第七章个人线场景插图

两条路线共 105 个阅读节点：阿喆 36、十元 69。每个节点一张独立场景图，按当前对白绑定到游戏和相册；不复用角色立绘代替情节。

- `plan.json`：14 张 4 列 × 2 行八合一的逐格场景清单。
- `01-personal.txt` 至 `14-personal.txt`：内置图像生成工具的提示词。角色参考来自项目现有立绘。
- `02-personal-fix.txt`、`04-personal-fix.txt`、`12-personal-fix.txt`：冰冰性别与气质、玩家视角及单场景构图的修订提示词。
- `art.json`：每张裁图的原图、原图尺寸、格号、裁切坐标、绑定 ID 和最终文件。坐标为 `[left, top, right, bottom]`，内缩 3 像素以去掉拼图分隔线。
- `assets/chronicle/personal/source/`：生成原图与修订前版本。第 14 张只使用第 1 格，其余为留存的空琴房细节图，不参与剧情收藏。
- `assets/chronicle/personal/<节点>.webp`：浏览器加载的最终图片。

重建：`python3 scripts/crop-personal-art.py`。只生成已存在批次时可传 `--partial`。不要只替换回忆详情图：剧情、相册、详情和下载共享同一图片映射。

已逐格检查八合一边界、剧情主体与分支情绪。冰冰为长发、亮眼优雅的女性大提琴手；雪子为短发男性，出现在 `sy_i3` 探班场景（第 11 张第 6 格）。玩家使用第一人称视角，避免在阿喆、十元线之间误配恋爱对象。
