## 已定位的结构性问题

- `js/features/moonlight-castle-ui.js:imageFor()` 只在日出塔楼切图，其他情况永远取 `CASTLE_ROOMS[room].art`。因此同房间三周目、日出与动作变化都展示同一 v3 图。不是只修暗度可解决。
- `renderPeople()` 依赖固定 `room.cast`；晨间大厅例外只放六个对话按钮。`imageFor()` 甚至注明房间构图不变。用户看到的“笛杰不见却在画上”“全员却只有两人”都由此产生。
- 当前 v3 参考服装有现代 Jerry T 恤牛仔裤、笛杰格衬衫、冰冰挂脖裙、宝石黑衬衫、飞鸿白外衫，均需按这次用户的新古堡服装锁重绘；不能只更新标签。
- 当前结局 `outcomes-v1` 为避免无角色参考而全部用无人物光效。这次用户已明确旧世面容为宝石/飞鸿，应以授权新基准重做画像与适合出现人物的结局行动。
- 当前 `CASTLE_OBJECT_REGIONS` 是原图百分比多边形。重绘后每张变体必须重新核对物件范围、人物坐标、门锚点。不能借同一 ID 假定坐标仍适用。

## 剧情内部需要显式展示事件的地方

以下均应保留原文，以展示状态解决，不能“修图”顺带改剧情。

1. **笛杰缺席与仍有台词。** 二周目房间直说不见，但 `DIALOGUES.dijie[2]` 有裂笛、东方曲、日记赠物等对话，第三周目还有吹笛送别。缺席的探索态不可画常驻笛杰；原有交谈进入 `study-loop2-talk-dijie` / `study-loop3-talk-dijie` 的显式会话片刻（可灵影显现），结束返回缺席。不能直接删掉全部笛杰功能或把其话当柒柒说。
2. **宝石飞鸿离场与透明告别。** 三周目探索明说两人不见、只留纸条；`DIALOGUES.servants[3][0]` 仍要两人微笑逐渐透明。独立 `dining-loop3-talk-servants` 告别，结束恢复无人的位置。不能让两位实体始终站在冰冰边上。
3. **伯爵缺席与交谈。** 二周目塔楼初到明确不在；交谈与献礼时才显形；献礼倒计时中包淡金光、声音在脑中。基础空图、红眼显形、金光禁锢不可用同张。
4. **盔甲状态不是TIM的状态。** 角落遗物全盔甲与TIM本人露头骑士甲分清。三周目及日出默认遗物倒地；日出TIM首句扶起它，之后若保持已读状态应显示扶正，不能马上再倒。二周目调查“面墙伸手”比房间第一句更具体，需要调查近景状态。
5. **肖像渐显的时机。** 三周目入房文字已说恢复，用户要点击逐渐显出宝石/飞鸿面孔。建议远景已是双人完整轮廓但暗中面部不明显，点击 `dining-loop3-portrait-veiled → reveal` 近景逐渐清晰。不要让入房仍是空画框/划毁到完全无人，造成恢复文字再冲突。
6. **早晨聚齐不意味着后续永久站原地。** 冰冰日出首句明确站画像前触框，可由厅入口进入 `dining-dawn-talk-bingbing` 当前会话近景；十元从厨房出来端面包、笛杰横笛在膝上、宝石飞鸿揉眼坐起仍牵手，不应都拿直立人像充数。
7. **转述与历史。** 叶执事说曾见两男人抱在一起、TIM回忆两人月下跳舞、十元说见过主人同睡、柒柒转述母亲伪信和小说人物，均不是当前两男人/母亲/《莫里斯》人物站进房间。需要插叙时单独历史画面并显式 `paintedCast`/回忆，不扩大现实 `visibleCast`。
