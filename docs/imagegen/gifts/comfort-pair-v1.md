## 使用方法

每次上传对应礼物参考图，将下方“通用要求”+该礼物“动作与声音”+“负面约束”合并发送给视频服务。支持附加人物参考时，同时上传上述两张正式立绘并标明角色。参考图是关键姿态，视频从该姿态开始做小幅自然动作，避免图生视频强行倒推复杂入场动作。

### 通用要求

使用对应参考图作为唯一人物与服装依据，制作《恋与哈基米》游戏内双人礼物动画。竖版 2:3，建议 1024×1536，10 秒，24 或 30 fps；平台只支持 9:16 时扩展纯色边缘，不裁掉人物。固定中景镜头，保持参考图的双人大小和位置，完整保留发顶、眼镜、双手，四周留安全边距。画风为细腻的半写实日系游戏插画，人物动作自然克制，脸部和服装全程一致。
两位都是成年男性。宝石：柔和脸型，蓬松略长黑发与长刘海，黑色衬衫和黑裤，无眼镜。飞鸿：较短利落黑发，明确的侧转鼻梁与下颌轮廓，矩形深色眼镜，白色外衫搭黑 T、银链、黑手套。不得互换发型、脸、服装和安慰者身份。
背景使用完全均匀的纯绿色 #00FF00，无纹理、无渐变、无投影、无场景、无绿色反光。角色及特效不使用绿色；黑发、黑衣、黑手套均为实色，不透明。若服务支持真实 Alpha 视频，可直接输出透明背景并省略绿底。不要输出黑色背景，不要模拟透明棋盘格。去掉参考图周围的大面积背光雾，只保留贴近人物的细光带和少量颗粒；不画礼盒、卡牌、界面、文字、价格或羁绊数字。
全片单镜头，不切镜、不推拉、不旋转。人物从首帧即可见，按参考姿态开始表演，最后 0.8 秒稳定停留，保持人物可见；后续由游戏负责入场、退场与飞向角色卡的动作，不生成黑场或淡入绿底的全画面转场。声音与动作同步，音乐与拟音柔和，有自然收尾，无人声对白。

### 宝石的安慰：动作与声音

画面对应礼物「宝石的安慰」，赠送对象是飞鸿：左侧黑衬衫、无眼镜的宝石是安慰者；右侧白外衫、戴眼镜和黑手套的飞鸿是接受安慰的人。
0—1 秒：沿用参考图宝石站在飞鸿身侧、双手扶在飞鸿肩上的姿势，飞鸿坐姿略显疲惫，只有自然呼吸和细微发丝摆动。
1—3.5 秒：宝石稍稍俯身看向飞鸿，嘴角浮现温柔笑意；一只扶肩的手轻轻拍一下，另一只手保持支撑，双手不换位、不出现多余手臂。
3.5—6 秒：飞鸿缓缓抬眼与宝石对视，眉眼放松，肩膀轻轻落下，露出释然的小笑容。不要夸张哭泣或大幅转头。
6—8 秒：细窄的香槟金与浅玫瑰色光带在两人腰侧绕过半圈，几枚小音符依次亮起，画面下方凝成一颗晶莹猫爪爱心；光效不遮挡脸和手。
8—10 秒：两人维持安定的陪伴姿态，猫爪爱心轻轻脉动一次，周围星点减弱，最后 0.8 秒稳定停留。
声音：起始是一颗温润的钢琴单音和极轻的空气流动声；扶肩轻拍同步自然、轻柔的衣料摩擦声，不要拍打音；飞鸿放松时进入三四个舒缓钢琴音，配很轻的弦乐长音；猫爪爱心凝成时响一声清澈短铃，尾声自然衰减，无轰鸣、无鼓点、无说话声。整体是“被温柔安慰后终于松一口气”。

### 飞鸿的安慰：动作与声音

画面对应礼物「飞鸿的安慰」，赠送对象是宝石：右侧白外衫、戴眼镜和黑手套的飞鸿是安慰者；左侧黑衬衫、无眼镜的宝石是接受安慰的人。
0—1 秒：沿用参考图，飞鸿从身侧轻揽宝石肩膀，一只戴黑手套的手自然落在宝石肩上，另一只手放在自己的腿上；宝石的双手自然放在自己膝前。
1—3.5 秒：飞鸿轻轻收拢搭肩的手臂，低头看向宝石，表情沉稳温柔，像在无声地说“我在”。动作只做很小幅度，不换手、不大幅移动身体。
3.5—6 秒：宝石轻轻向飞鸿肩侧靠近一点，完整露出脸部，眨眼后眼神放松，嘴角出现安心的笑意；飞鸿的目光保持关注宝石。
6—8 秒：银紫色的细光带在两人腰侧缓缓弯成一道守护弧，少量银色音符依次亮起，画面下方凝出带猫爪纹样的水晶爱心；没有厚重屏障或满屏雾气。
8—10 秒：两人保持安静相依的姿态，水晶爱心轻轻脉动一次，细碎星光收敛，最后 0.8 秒稳定停留。
声音：开场为低而温暖的钢琴和弦，轻柔大提琴长音缓慢进入；揽肩时只有轻微白衬衫与手套的衣料摩擦声；靠近时有一层极轻的空气声；银紫光带环绕时加入克制的玻璃泛音，水晶爱心凝成时落下一颗明亮钢琴高音，最后自然延音收尾。无人声对白、无战斗音效、无突然爆响。整体是“有人稳稳接住你”的安心感。

### 负面约束

避免：换脸、把两人画成同一张脸、女性化身体、儿童比例、宝石戴眼镜、飞鸿没有眼镜或黑手套、错误旧版服装、手指增生、手臂穿模、眼镜变形、漂浮手掌、嘴部无意义说话、角色视线漂移、过度拥吻、夸张哭泣、镜头旋转、大幅推拉、文字字幕、品牌标志、黑底、灰底、渐变绿幕、绿光染到白衣和皮肤、黑衣透明、全屏光雾、闪白、剪辑转场。

## 游戏接入说明

两人都有黑发、黑衣，飞鸿还有黑手套，不能对整段素材使用统一亮度阈值去黑。优先使用真实 Alpha；没有 Alpha 时用纯绿底做色度抠像，并检查发丝、眼镜、黑衣、手套、白衬衫边缘的透明度与溢色。未经检查不直接套用心动安可的黑底阈值。

沿用已确认礼物仪式：游戏礼盒入场与打开 → 双人安慰动画 → 将猫爪爱心送向真实收礼角色卡 → 回执与羁绊条补间。影片本身不烘焙游戏背景、卡牌、矩形画框、遮罩、开盒或 UI 数字；根据媒体时钟衔接，支持跳过、静音、切页清理。统一结算先保存，动画只负责表现，不再次发奖。专属视频加载失败时展示对应双人透明参考图并收尾；未配置专属主题的其他礼物仍回退猫爪送心。

## 手机发布版

使用 `scripts/build-gift-delivery.py` 从已确认透明母版生成 480×854 的 VP9 Alpha WebM 与 HEVC Alpha MOV；iPhone／iPad／Apple WebKit 使用 MOV。它们保留原声和时间轴，MOV 元数据前置（faststart）。旧 WebM 在部分 Apple 解码器中可播放但丢失 Alpha，会出现黑色矩形，不能只凭 canPlayType 判定透明兼容。实际体积见 `delivery-sizes.json`。预载只针对当前所选礼物，播放复用同一视频元素。
