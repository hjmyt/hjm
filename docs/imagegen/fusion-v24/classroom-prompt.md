- `fusion-classroom-01.png`：开场 1–6、课程 1–2。
- `fusion-classroom-02.png`：课程 3–7、小考 1–3。

高风险约束：钢琴白键前沿朝演奏者、黑键位于远侧；吉他、贝斯、萨克斯、竹笛必须有手、背带、琴凳或支架支撑；结果页答题纸完全空白，不使用生成模型做精确计数；结果页现场只允许垃垃与老杜，Jerry 已答完题但不入镜；老杜以正式人物立绘的黑衬衫、深色西装与花纹围巾为准。
