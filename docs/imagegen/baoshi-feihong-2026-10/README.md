- 配角使用各自完整立绘。融合线玩家仍是 Jerry（黑短袖、蓝牛仔裤、矩形眼镜），不得由飞鸿或匿名主角替代。

## 文件与重建

- 用户原图：`assets/characters/source/baoshi-2026-10.png`、`feihong-2026-10.png`。
- 卡面坐标：本目录 `card-crops.json`。执行 `python3 scripts/crop-baoshi-feihong-cards.py`，然后 `node scripts/build-card-thumbnails.cjs`。
- 生图方式：Codex 内置 `image_gen`，每次生成一张四列两行、八个正方形场景的母图。提示词为本目录 `bf-*.txt`，参考图顺序记录在 `plan.json`。支持角色对照图只是从现有立绘制作的参考索引，不是交付剧情图。
- `plan.json` 保留原始剧情摘要、精简分镜、参考图和输出路径；`art.json` 记录最终母图、格号、像素裁切坐标和生成提示词。后面的 QA 格覆盖前面的同 ID 格。
- 母图保存在 `assets/chronicle/personal/source/`、`assets/chronicle/scenes/source/`、`assets/fusion/source/` 中。跨类别合并的母图可服务多个目录；具体来源以清单为准。
- 执行 `python3 scripts/crop-baoshi-feihong-art.py` 重建全部本次裁切。原有 personal、chronicle、album、fusion 裁切入口也会应用本次更新。
- 原图片和原始母图保留以便追溯；当前资源使用 `-bf202610` 文件名避开旧图片缓存。卡牌缩略图附加 `?v=bf202610`。人物、剧情、回忆、分支和存档 ID 不变。
