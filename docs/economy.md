# 音符经济

2026-09-24 起：音符是正传与卡册共用的唯一消费货币。取消正传体力、团费和回血操作，保留战斗回合状态、猫咪精力与角色合奏精力。

| 项目 | 规则 |
| --- | --- |
| 新档余额 | 30 音符 |
| 口令礼包 | 首次 10 音符 |
| 角色故事 | 首次读完 3 音符；羁绊和回忆规则不变 |
| 每日任务 | 10 音符、1 张邀请券；演奏任务须完整达到 C |
| 免费节奏演奏 | 完整演奏且有手动命中，准确率达到 45%；C/B/A/S 分别为 3/4/5/6 音符 |
| 编队与主动技能 | 音符加成合计最多 +2；不改变原有角色特殊效果 |
| 演奏次数 | 当天前 3 场达标正常发放，第 4 场起总共 1 音符；失败、中断不占次数 |
| 章节完成 | 每章首次 15 音符、1 张邀请券，其他结局仅收录回忆 |
| 第二、四章赞助 | 每个节点首次 +5，跨重开保留领取记录 |
| 正传考核 | 免费，不增加琴技；每日首次通过 +3，首次通过另 +3 |
| 阿喆安可 | 每日首次 +2，之后仍有经验与纪念，无额外音符 |
| 首席四拍练习 | 每日首次合格 +5，沿用原有每日限制 |
| 正传练琴／延期加练 | 10 音符 → 琴技 +2；延期另推进 1 周 |
| 投喂 | 10 音符 → 羁绊 +1，每角色每日最多 3 次 |
| 柠檬借款 | 20 音符，不得透支；羁绊奖励仍按节点去重 |

剧情自带的琴技奖励每章每节点仅一次；刷新、重开、再遇到相同事件不能重复增长。余额不足时练琴按钮不可用，后端动作也再次校验；周常提供免费的「演奏赚音符」入口，避免无法继续培养。

一般活跃日以约 25～35 音符为调参参考，并非强制每日总上限。7～10 个活跃日达到 35 羁绊以重点培养一位角色为参考，兼顾练琴或同时培养多人会更慢。

旧档保留现有音符、琴技和养成，不将退役团费兑换为音符。永久领奖记录与每日次数独立于章节保存。根据旧档结局、章节完成、赞助状态及仍保存的已选剧情记录补齐领取状态；旧档已丢失的早期剧情记录无法推断。迁移可重复执行，不重复扣款或发奖。
