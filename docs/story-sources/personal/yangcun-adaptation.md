# 羊村线 · 原稿迁移说明

剧情唯一文本源为用户提供的《羊村线-剧本版 v2.0》，已原样保存在 `docs/story-sources/personal/yangcun.html`。正式版本不再对正文、对白、选项、分支或结局进行概括改写；构建脚本直接读取附件 `<textarea id="script">` 内的 57 个剧情节点。

产品层只做三类适配：将原文按每屏最多两个发言回合分页；把原型的 `NEXT`、自动分流与积分结算接入第七章存档；按照项目统一规则使用全局羁绊判定角色分流，不新增独立好感资源。乐队积分与担当值仍按原稿保留为羊村线内部记录。

第二章达到乐队 Lv.6 并选择羊村后永久解锁本线，同时继续原第二章；完成第六章后也可支付 10000 音符永久解锁。路线入口不再强调固定人数。

正文共拆为 141 个阅读分页，每页绑定一张独立插图。图片使用 18 张 4×2 母图生成并裁切；角色必须对应卡册立绘。柒柒的立绘只锁定身份与服装，原文没有演奏时不携带吉他；REK 固定为成年男性，并使用用户提供的正式立绘作为参考。

REK 卡牌默认锁定；玩家实际读到羊村开篇中 REK 首次登场的分页时，才获得卡牌并加入后续招募池。
