# 可复用角色音色

`assets/characters/voices/registry.json` 是角色音色的统一目录；每个角色还有独立 `metadata.json`、用户原始 WAV 和 24kHz 单声道 `reference.wav`。角色音色与语言、服装、章节分开保存，后续新增剧情优先按 `cardId` 或别名查找此目录，不再从临时微信路径取音色。

2026-10-17 月光古堡采用用户附件提供的宝石、飞鸿、十元、垃垃、笛杰、冰冰、艾德里安、Jerry、Tim、叶执事及柒柒参考。菲利克斯按用户单独确认沿用旧参考音色。叶执事的古堡语音 ID 为 `siyang`，正式人物卡 ID 为 `yeshiyang`；其他已入卡角色使用各自卡牌 ID，古堡原创人物的 `cardId` 为 null。

元数据包含原文件名、原始／规范化音频 SHA-256、参考时长、声道、采样率、角色名和别名、来源类型、用户确认日期与默认后期音高。11 个新参考均不做额外变调；菲利克斯保留旧配音既有的 +1.3 半音设置。参考音频只承担身份与音色基准，不能把参考中的情绪套给所有台词。

新配音统一使用 IndexTTS-2.5；模型仍位于 `/Users/hxj/.cache/huggingface/indextts2.5/checkpoints`，不复制到游戏目录。每句的语言、文本、实际语境、前后文、情绪向量、语速与输出映射另存在相应剧情配音计划中。更改参考音色时须同步更新 SHA-256 并重建受影响声音，不自动给其他角色换声。
