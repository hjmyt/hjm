1. 背景与目标

用户计划未来把正传里的“空格的考验”换成音准小测试，但要求先做成独立小游戏，确认玩法无误后再讨论接入。

本轮成功标准：玩家能在不看到赫兹数的情况下完成“听出错音 → 判断方向 → 旋钮调音 → 获得逐项得分”的完整闭环，并能在桌面端和手机端直接打开 HTML 游玩。

明确不在本轮范围内

  • 不修改 js/chronicle/、剧情节点、考核奖励或存档。
  • 不消耗音符，不发琴技、羁绊、回忆或音符奖励。
  • 不决定最终替换哪一个剧情节点，也不处理旧存档迁移。

2. V1 规则 NEW

项目V1 约定设计理由
题量固定 3 题，每题 6 个音足够验证玩法，不让预览过长
错音每题只有 1 个音偏离；三题依次为 +10、−9.5、+6.75 Hz从明显差异过渡到较细微差异
参考可无限播放标准旋律、考核旋律和 A4 标准音满足“需要给标准音”的讨论结论
识别分错音位置与偏高/偏低均正确，得 1 分把“找到不准的音”定义为完整判断
调音分最终误差 ≤ 3 Hz，得 1 分采用截图讨论中的允许误差
旋钮调节范围 ±16 Hz、步进 0.25 Hz，不显示当前数值可做粗调与细调，同时避免数值提示答案
总分3 题 × 2 分，共 6 分；4 分暂定为合格识别与动手调音都计入结果

3. 操作流程

播放标准音/标准旋律播放考核旋律选择错音与偏差方向旋钮调音并试听逐题结算与总分

第一步：识别

界面展示六个简谱数字及音序位置。播放时逐音高亮，但不会标出哪一个音被修改。玩家选择一个音，并选择“偏高”或“偏低”。两项都正确才获得识别分。

第二步：调音

系统揭晓实际错音后，玩家仍可独立争取调音分。旋钮不显示 Hz，只显示“偏低 / 标准位置 / 偏高”的方向文字。可拖动旋钮、点按 ＋/−，或使用键盘方向键微调。

第三步：反馈

提交调音后才显示最终误差，并明确是否落在 ±3 Hz 内。每题分别显示识别分与调音分，最后汇总 6 分制成绩。

4. 状态与边界

  • 音频启动：所有声音由玩家点击后启动，符合浏览器自动播放限制；后台或离开页面时立即停止。
  • 答错不锁死：识别错了仍可继续调音，两个分项相互独立，便于学习与评审。
  • 无限试听：标准音、正确旋律、考核旋律和当前调音结果都可重复播放，不扣分。
  • 设备兼容：桌面支持鼠标拖动与方向键；手机支持触摸拖动及 ＋/− 微调。
  • 无正式副作用：刷新即重置，不写入主游戏存档，也不使用主游戏经济或奖励键。
音色说明：V1 使用浏览器 Web Audio 合成的清晰长音，重点验证音高玩法；正式接入前再决定是否换成采样小提琴音色。

6. 待你试玩后确认

  1. 每局 3 题是否合适，还是正式版只做 1 题或做 5 题？
  2. “位置 + 偏高/偏低都正确才得识别分”是否符合你的计分预期？
  3. 识别答错后揭晓正确音、仍可争取调音分，还是应该直接进入下一题？
  4. ±3 Hz 是否最终保留；第三题约 6.75 Hz 的初始偏差是否太明显或太难？
  5. 正式版要沿用合成音色，还是使用更接近小提琴的采样音色？
  6. 最终接入时，是替换第一次入团考核，还是替换所有自由合练考核？
你确认玩法前，这些项目都只停留在预览目录，不进入剧情实现。
